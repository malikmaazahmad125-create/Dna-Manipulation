# 🧬 DNA Manipulation

A Python-based DNA Manipulation project that performs DNA sequence analysis, reverse complement generation, codon analysis, FASTA file handling, NumPy statistics, Pandas data analysis, data cleaning, and visualization using Matplotlib and Seaborn.

---

## 🚀 Features

This project performs:

- 🧬 DNA Sequence Analysis
- 📏 DNA Sequence Length Calculation
- 🔍 First Four Characters Extraction
- 🧪 GC Content Calculation
- 🔄 DNA Reverse Complement
- 🧬 Codon Analysis and Counting
- 📁 FASTA File Creation and Reading
- 🔢 DNA Encoding using NumPy
- 📊 Gene Expression Statistics
- 🐼 Pandas DataFrame Creation
- 🧹 Missing Data Cleaning
- 📈 Descriptive Statistics using `describe()`
- 📊 Data Visualization using Matplotlib
- 📉 Data Visualization using Seaborn

---
How to Run:
python "Dna Manipulation.py"
